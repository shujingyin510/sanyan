# 三言 Playground（在线演示）

在浏览器里运行三言（平衡三进制中文编程语言）的**纯静态、零服务器**在线演示。
代码在访问者的浏览器里即时求值——无需后端、首屏加载后无需联网。

> **在线试玩**：`https://shujingyin510.github.io/sanyan/playground/`（启用 GitHub Pages 后）

## 这是什么

`index.html` 是一个**完全自包含**的单文件（约 36 KB，零外部依赖：无 CDN、无外链字体/脚本、无 fetch）：

- 一个用 JavaScript 实现的三言**核心子集**解释器（词法 → 语法 → 求值）
- 编辑器 + 运行 + 输出控制台的 UI（墨 / 宣纸双主题）
- 签名特性：**每个整数输出都揭示其平衡三进制**表示，`+`（真）/ `0`（可能）/ `−`（假）三色显示

因为零依赖，它可以：

- **双击直接打开**（任何现代浏览器，离线可用）
- 把文件发给别人，对方双击即用
- 丢到任意静态托管（GitHub Pages / Netlify / Vercel / Cloudflare Pages）

## 如何用 / 如何分发

| 方式 | 步骤 | 适合 |

### 托管到 GitHub Pages（推荐的公开入口）

1. 提交并 push `playground/` 到仓库
2. 仓库 **Settings → Pages → Source** 选 `main` 分支、根目录 → Save
3. 约 1 分钟后上线：`https://<用户名>.github.io/sanyan/playground/`
4. 在主 README 顶部挂「▶ 在线试玩」链接指过去

> 免费前提：仓库为 public（开源语言项目通常是）。私有仓需 GitHub Pro。

## 支持的语言子集

- **变量**：`设 x = 值`、裸赋值 `x = 值`、`置`（设备写）
- **函数**：`定义 名 (参数) { … 返回 值 }`、`函数(参数){…}` 匿名、递归
- **控制流**：`若 / 再若 / 否则`、`遍历 … 从 … 到 …`、`遍历 … 在 …`、`循环 (…)`、`跳出` / `继续`
- **三态分支 `判`**：`判 值 { 真 {…} 可能 {…} 假 {…} }`（按符号 >0/=0/<0 选支）
- **运算符**：算术 `加 减 乘 除 余 幂`（符号 `+ - * / % ^`）、比较 `大于/小于/等于/不等于/大于等于/小于等于`（符号 `> < = == != >= <=`）、**Kleene 三值逻辑** `且`(min) / `或`(max) / `非`(取反)
- **三态词表**（21 词，对齐 `core/ternary_core.py` 的 `STATE_MAP`）：
  - `开 高 真 亮 启 通 有 是` = +1
  - `关 低 假 灭 停 断 无 否` = −1
  - `守 中 可能 待 未知` = 0
- **数据**：整数（平衡三进制）、字符串、列表 `[…]`、字典 `{"键": 值}`
- **异常**：`尝试 { } 捕获 (e) { }`
- **内置**：`输出 连接 取长 表长 取 查找 前缀 字符串包含 求和 最大值 最小值 绝对值 平方根 排序 反转 大写 小写 同 取键 置键 含键 …`
- **浏览器桩**（非确定/无副作用）：`随机态 随机数 读 等待 读文件`(→ `""`) `写文件`(→ 空操作) `当前时间`

## 已知边界（相对完整语言）

- 这是核心子集的**忠实再实现**，**不是**真正的编译器 / VM。完整语言 —— 自举编译器链（Level 0–4）、字节码 VM、C / LLVM / NASM 四后端、AI 智能体系统 —— 见仓库根。
- 无模块 `导入`、无完整标准库、无真实文件 I/O（浏览器桩）
- `随机态 / 随机数` 为浏览器随机，输出不可复现（求值器本身也随机）
- 平衡三进制显示取**规范最简形式**；求值器算术偶尔保留位宽（如 `1 + 0` 显示 `0+`），数值一致、仅前导零标注不同

## 正确性验证

JS 解释器的输出以仓库内 **Python 求值器（Level 0 参考实现）** 为准，用 Node headless 逐例差分：

- 5 个确定性示例（平衡三进制 / 三态分支 判 / 斐波那契 / FizzBuzz / 阶乘）**值逐行一致**，其中 4 个含三进制标注逐字节一致
- README 的完整**温室控制**示例（10 次检测 + 灯/窗帘/风扇/加热 全设备控制 + `尝试-捕获`）端到端跑通、零异常
- 边界对抗（死循环 / 除零 / 未定义 / 未闭合 / 深递归）全部优雅捕获，不挂起、不裸崩
