# 三言 Agent — 三态推理智能体 + 村庄模拟

基于三言编程语言实现的具备不确定性感知的推理 Agent，以及从双人 NPC 到 8 人村庄的全链路行为模拟。

## 快速开始

### 1. 配置 API 密钥（三选一）

```bash
# 方式一：环境变量（推荐）
set SANYAN_API_KEY=sk-你的密钥    # Windows
export SANYAN_API_KEY=sk-你的密钥  # Linux/Mac

# 方式二：直接写到策略文件
# 编辑 ternary_agent/agent_policy.san，修改第 14 行：
#   设 API密钥 = "sk-你的密钥"

# 方式三：游戏配置文件
# 编辑 ternary_agent/runtime_v2/village_config.san
```

### 2. 选择模型提供商（可选）

编辑 `ternary_agent/agent_policy.san`：

```san
设 模型提供商 = "deepseek"   # deepseek / openai / qwen / gemini / mimo / ollama / custom
设 模型URL = "https://api.deepseek.com/v1/chat/completions"
设 模型名 = "deepseek-chat"
```

支持 6 家：**DeepSeek** | **OpenAI** | **千问** | **Gemini** | **小米MIMO** | **Ollama**

### 3. 启动

```bash
# Agent — 可读决策 DSL（v0.3）
python -X utf8 run_agent.py                    # 多轮对话
python -X utf8 run_agent.py "你的问题"          # 单次提问

# v2: NPC 双人游戏（老王 & 李婶）
python -X utf8 run_v2.py game                  # 交互式对话

# v3: 桃花村 8 人模拟（完整村庄）
python -X utf8 run_village_demo.py             # 10 天自动演示
python -X utf8 run_v2_demo.py                  # 30 天 NPC 记忆演示
```

## v0.2 三态 Agent — 核心概念

### 三态决策

Agent 将 LLM 返回的 5 种认知态映射为三进制决策：

| 认知态 | 三态值 | 含义 |
|---|---|---|
| AFFIRM | 真 (1) | 确信，直接输出 |
| NEGATE | 假 (-1) | 否定，拒绝执行 |
| UNCERT / CONFLICTED / PENDING | 可能 (0) | 不确定，触发工具或反问 |

### 犹豫保护

当连续多轮处于"可能"态时，系统会调用工具获取更多信息、询问用户补充上下文、超限后用多数投票强制决策，高风险操作直接拒绝。

### 传播规则

上游假→下游必假，上游可能+下游真→降为可能（保守策略）。

### 冲突检测

当 LLM 返回 `CONFLICTED` 时自动记录冲突，跨轮累计统计。

## 关键设计决策

| 决策 | 原因 |
|---|---|
| 数值 x100 整数化 | 三言无原生浮点，强度/权重/衰减 0-100 表示 |
| 内联全部子系统 | 模块编译依赖复杂，v3 自包含 520 行单文件 |
| NPC 前缀键名 | `NPC_事件类型` 隔离不同 NPC 记忆（如 `老王_苹果`） |
| 传闻逐跳传播 | 最多 3 跳，关系类型决定传播速度，模拟现实扩散 |
| 声望趋近好感 | 每日好感 ±1 向声望值靠拢，模拟舆论影响 |
| (想了想) 前缀 | 不确定回应可视化可能态，传承 v0.2 犹豫保护理念 |
