# 未来扩展路线图

## 短期（1 个月内）

### 价值度 + 引用计数
- **触发条件**：对话轮 > 50
- **插入点**：`context_mgr.san`
- **内容**：根据上下文片段的被引用次数加权保留

### 时间衰减
- **触发条件**：对话轮 > 100
- **插入点**：上下文压缩阶段
- **内容**：越旧的上下文权重越低，引入衰减因子

## 中期（1–3 个月）

### 认知×执行 双轴分支
- **触发条件**：决策复杂度不可控
- **插入点**：`decision.san`
- **内容**：将当前 5→3 映射升级为完整的 5×5 双轴矩阵

### 链接 Node.js MCP
- **触发条件**：工具需求增长
- **插入点**：`tool_sched.san`
- **内容**：支持 MCP 协议对接外部工具

## 长期（3–6 个月）

### Claim Graph
- **触发条件**：冲突率 > 30% 且来源 > 5
- **插入点**：新建 `claim_graph.san`
- **内容**：构建知识主张图，追踪每个结论的来源链和置信度

### 多 Agent 协作
- **触发条件**：PoC 通过
- **插入点**：新建 `multi_agent.san`
- **内容**：多个三态 Agent 实例协作，通过消息队列通信

### 长期记忆
- **触发条件**：会话 > 100
- **插入点**：扩展 `memory.san`
- **内容**：持久化存储 + 向量检索 + 语义相关度排序
