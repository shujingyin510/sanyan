## 数据流

```
  世界状态（_V字典）
      │
      ▼
  NPC感知（取行为/天气影响/时段切换）
      │
      ▼
  三态决策（记忆匹配→好感→状态→回复选择）
      │
      ▼
  行为输出（送礼/借钱/帮忙/打听/聊天）
      │
      ▼
  世界更新（声望调整→传闻广播→好感变化→记忆创建）
      │                                 │
      └─────────────────────────────────┘
             循环至下一天
```

## 关键设计决策

| 决策 | 原因 |
|---|---|
| 数值 x100 整数化 | 三言无原生浮点，强度/权重/衰减 0-100 表示 |
| 内联全部子系统 | 模块编译依赖复杂，v3 自包含 520 行单文件 |
| NPC 前缀键名 | `NPC_事件类型` 隔离不同 NPC 记忆（如 `老王_苹果`） |
| 传闻逐跳传播 | 最多 3 跳，关系类型决定传播速度，模拟现实扩散 |
| 声望趋近好感 | 每日好感 ±1 向声望值靠拢，模拟舆论影响 |
| (想了想) 前缀 | 不确定回应可视化可能态，传承 v0.2 犹豫保护理念 |
