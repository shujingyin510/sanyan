# 三态 Agent Runtime v2 — 实现计划

## 概述

在 v0.2 基础上新增两个核心系统：
1. **时间记忆** — 带强度衰减的持久化记忆节点
2. **关联激活** — 节点间的加权关联图，支持联想传播

## 一、时间记忆系统

### 记忆节点结构

```
节点 = 字典(
    "id",       记忆ID（字符串）
    "内容",     记忆内容（字符串）
    "状态",     认知三态值: 1(真)/0(可能)/-1(假)
    "创建时间", 时间戳
    "最后访问", 时间戳
    "访问次数", 整数
    "强度",     0-100（整数化浮点）
    "TTL",      过期秒数
    "来源",     记录来源
)
```

### 强度计算（整数版）

原始浮点公式：`强度 *= e^(-λ * Δt)`

三言整数近似（100 = 1.0）：

```
定义 时间衰减 (节点) {
    设 已过秒 = 时间戳() - 节点.最后访问
    设 衰减因子 = 100 - (已过秒 * 衰减率 / 100)
    若 (衰减因子 < 0) { 设 衰减因子 = 0 }
    设 节点.强度 = 节点.强度 * 衰减因子 / 100
}
```

### 访问增强

```
定义 访问增强 (节点) {
    设 节点.访问次数 = 节点.访问次数 + 1
    设 节点.强度 = 节点.强度 + 5
    若 (节点.强度 > 100) { 设 节点.强度 = 100 }
    设 节点.最后访问 = 时间戳()
}
```

### 遗忘清理

```
若 (节点.强度 < 5) { 删除记忆(节点.id) }
```

### 效果

```
访问频繁 → 强度上升 → 保留更久
长久不访问 → 强度衰减 → 逐渐遗忘
近期提及 → 强度高 → 优先回忆
```

## 二、关联激活系统

### 关联图结构

```
节点 = 字典(
    "名称", 概念词（字符串）
    "激活值", 当前激活度 0-100
)

边 = 字典(
    "源", 源概念名
    "目标", 目标概念名
    "权重", 关联强度 0-100
)
```

### 示例关联图

```
苹果 ──80──→ 水果 ──60──→ 维生素 ──50──→ 健康
 │                                      
 └────70──→ 红色 ──40──→ 热情          
```

### 激活传播

```
定义 激活传播 (起始概念) {
    设 起始节点 = 取关联节点(起始概念)
    起始节点.激活值 = 100
    
    遍历 每条出边 {
        设 目标 = 取关联节点(出边.目标)
        设 传播值 = 起始节点.激活值 * 出边.权重 / 100 * 衰减系数 / 100
        目标.激活值 = 目标.激活值 + 传播值
        若 (目标.激活值 > 100) { 目标.激活值 = 100 }
    }
}
```

### 联想输出

```
定义 取活跃概念 () {
    设 结果 = 列表()
    遍历 所有节点 {
        若 (节点.激活值 > 30) { 结果 = 列表合(结果, 列表(节点)) }
    }
    返回 结果
}
```

## 三、三态推断

记忆状态驱动行为判断：

```
输入: 用户问题
  ↓
匹配关联图 → 激活相关概念
  ↓
检索高激活记忆
  ↓
计算三态值：
  多数记忆为真(1) → AFFIRM
  多数记忆为假(-1) → NEGATE
  无相关记忆 → UNCERT
  记忆互相矛盾 → CONFLICTED
  ↓
输出: 行为和回答
```

## 四、NPC Demo

### 角色定义

```
设 NPC = 字典(
    "名字", "老王",
    "好感度", 50,
    "记忆表", 字典(),      // 时间记忆节点
    "关联图", 字典(        // 关联概念
        "苹果", 字典("水果", 80, "红色", 70),
        "水果", 字典("维生素", 60, "健康", 50),
        "红色", 字典("热情", 40)

```

### 30天行为演化

| 天数 | 事件 | 效果 |
|---|---|---|
| Day1 | 玩家送苹果 | 记("苹果", 1, "玩家"), 好感+10, 强度100 |
| Day3 | 玩家借钱 | 访问增强("苹果")→联想"借钱", 好感-5 |
| Day7 | 玩家送水果 | 激活"苹果"→"水果"→"维生素", 强度维持 |
| Day15 | 无互动 | 苹果记忆强度衰减至60 |
| Day30 | 无互动 | 苹果记忆强度<5 → 遗忘, NPC恢复默认 |

### 对话演示

```
Day1 > 你好老王
  => 老王：你好！(好感55, 记得你送过苹果)

Day3 > 借我点钱
  => 老王：上次你送过苹果...好吧，借你。(好感50)
  => 冲突统计: 苹果(+1) vs 借钱(-1) → CONFLICTED

Day7 > 最近怎么样
  => 老王：挺好的，你上次送的苹果很甜！(苹果记忆强度90)

Day30 > 你好老王

```

## 七、技术约束

- **整数化**：所有浮点数乘以100用整数表示（强度、权重、激活值范围 0-100）
- **衰减率**：默认每天衰减 5%（`衰减率 = 5`，即每86400秒衰减5分）
- **Python求值器**：浮点运算和 math 函数通过 Python 求值器桥接
- **持久化**：记忆表和关联图存为 JSON 文件
