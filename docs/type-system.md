# 类型系统

> 三言的渐进类型系统：类型标注、类型推断、泛型容器、接口/协议、效应类型。

## 类型标注

```sanyan
定义 add (a: 数字, b: 数字) -> 数字 {
    返回 a + b
}
```

调用时自动校验参数类型。支持的类型名：

| 类型 | 说明 |
|------|------|
| `整数` / `int` | 整数 |
| `浮点` / `float` | 浮点数 |
| `字符串` / `str` | 字符串 |
| `列表` / `list` | 列表 |
| `字典` / `dict` | 字典 |
| `数字` / `num` | int 或 float |
| `任意` / `any` | 任意类型 |

## 可选类型

```sanyan
定义 f () -> ?数字 {
    若 (条件) { 返回 42 }
    返回 可能  // 表示"不确定"
}
```

`?类型` 接受指定类型或三态值 `可能`（未知）。

## 效应类型

```sanyan
定义 g () -> 确定[数字] {
    返回 42   // 编译期确定
}

定义 h () -> 不确定[数字] {
    返回 读文件("data.txt")  // 运行期确定
}
```

`确定[X]` / `不确定[X]` 编译期类型检查。

## 类型推断

变量类型自动推断：

```sanyan
设 x = 42          // x: int
设 y = "hello"     // y: str
设 z = x + y       // 类型错误
```

在 REPL 中用 `:types` 查看当前作用域类型。

## 泛型容器

```sanyan
列表<数字>                     // 整数列表
字典<字符串, 数字>              // 键字符串，值数字
列表<字典<字符串, 整数>>       // 嵌套泛型
```

支持嵌套泛型匹配。

## 接口 / 协议

```sanyan
定义 process (x: 可序列化) { ... }
定义 iterate (x: 可迭代) { ... }
```

运行时检查对象是否满足协议。内置协议：
- `可序列化` — 可转为 JSON
- `可迭代` — 支持遍历
- `可调用` — 可被调用

## 宏系统

```sanyan
守护 条件 { ... }          // 条件执行
除非 条件 { ... }          // 条件不满足时执行
当 条件 { ... }            // 条件循环
重复 N { ... }             // 固定次数循环
管道 val step1 step2       // 链式数据传递
```
