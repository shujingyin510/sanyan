# 三言快速入门

三言（Sanyan）是一门内置三态逻辑的中文编程语言。本文档帮你 5 分钟上手。

## 安装

```bash
pip install sanyan
```

## Hello World

```bash
python main.py
```

进入 REPL 后尝试：

```
三言> 输出("你好，世界")
三言> 设 a = 10
三言> 输出(a ^ 2)
三言> 设 状态 = 可能
三言> 输出(状态)
```

## 第一个程序

创建 `hello.san`：

```c
// 智能温室示例
定义 温室控制 () {
    设 温度 = 随机数(10, 35)
    输出(连接("当前温度：", 温度))

    若 (温度 > 30) {
        置 风扇 = 开
        输出("风扇启动")
    } 再若 (温度 < 15) {
        置 加热 = 开
        输出("加热启动")
    } 否则 {
        置 风扇 = 守；// 保持当前状态
        输出("温度适宜")
    }
    返回(0)
}

温室控制()
```

运行：
```bash
python main.py hello.san
```

## 核心概念

### 三值逻辑

三言内置三种状态：

| 值 | 中文 | 含义 |
|---|------|------|
| 1 | 真/开/亮/有 | 确定的肯定 |
| 0 | 可能/守/待/中 | 不确定 |
| -1 | 假/关/灭/无 | 确定的否定 |

```c
// 不确定时保持原状——不需要额外状态变量
若 (读(传感器) == 可能) {
    置 设备 = 守；
}
```

### 两种语法

三言支持两种等价语法：

**糖语法**（类 C，日常使用）：
```c
设 x = 10
若 (x > 5) { 输出("大") }
```

**S 表达式**（Lisp 风格，适合元编程）：
```
(设 x 10)
(若 (大于 x 5) (输出 "大"))
```

### 核心关键字

| 关键字 | 作用 |
|--------|------|
| `设` | 定义变量 |
| `若` / `再若` / `否则` | 条件判断 |
| `循环` | 循环 |
| `遍历` | for 循环 |
| `定义` | 定义函数 |
| `返回` | 函数返回 |
| `尝试` / `捕获` | 异常处理 |
| `输出` | 打印 |
| `导入` | 导入模块 |
| `判` | 三态分支 |

## 内置操作速览

```c
// 算术
加(1, 2)         // → 3
减(10, 3)        // → 7
乘(4, 5)         // → 20
除(10, 2)        // → 5

// 比较
大于(5, 3)       // → 1 (真)
等于(1, 2)       // → -1 (假)

// 逻辑
非(真)           // → -1 (假)
真 且 假         // → -1 (假)
真 或 假         // → 1 (真)

// 字符串
连接("hello", " world")  // → "hello world"
取长("abc")              // → 3
分割("a,b,c", ",")       // → ["a", "b", "c"]
子串("hello", 0, 3)      // → "hel"

// 列表/字典
列表(1, 2, 3)            // → [1, 2, 3]
取([1, 2, 3], 0)         // → 1
字典("a", 1, "b", 2)     // → {"a": 1, "b": 2}
取键({a:1}, "a")         // → 1

// 类型判断
是数字(42)               // → 1 (真)
是字符串("hello")        // → 1 (真)
是列表([1, 2])           // → 1 (真)

// 随机
随机数(1, 10)            // → 1~10 间随机数
随机态()                 // → 随机三态值 (-1/0/1)

// IoT 操作
注册设备("温度传感器", "")
置("风扇", 开)
读("风扇")
查("风扇")

// JSON
解析JSON('{"a":1}')      // → {"a": 1}
转JSON({"a": 1})         // → '{"a": 1}'

// HTTP
http读("https://httpbin.org/get")
http写(url, 数据, headers)

// 时间
时间戳()                 // → Unix 时间戳
等待(1000)               // → 等待 1 秒

// 文件
读文件("path.txt")
写文件("path.txt", "内容")

// 模块
导入("stdlib/math.san")
```

## 常见问题

**Q: 如何运行 .san 文件？**
```bash
python main.py myfile.san         # Python 求值器
python main.py --vm myfile.san    # VM 执行（更快）
```

**Q: 如何编译为可执行文件？**
```bash
python -m llvmgen.build myfile.san -o myapp
```

**Q: 全角/半角符号区别？**
支持全角符号（"，"、"（"、"）"），与半角等价。中文输入法可直接编码。

**Q: 如何切换英文关键字？**
REPL 中输入 `切换英文` 或 `:lang english`。
