## 2. 基础语法

三言支持两种语法风格，可以混用：

| 风格       | 示例            |
| ---------- | --------------- |
| 糖语法     | `设 a = 10;`    |
| S 表达式   | `（设 a 10）`   |

本文档以糖语法为主进行说明。分号在糖语法中可选（语句结束时可写可不写）。

### 2.1 变量与赋值

```
设 变量名 = 值;
```

```c
设 年龄 = 25;
设 名字 = "小明";
设 状态 = 开;
```

支持多重赋值（省略 `设`）：

```c
a = 1;
b = 2;
c = 3;
```

### 2.2 注释

```c
// 单行注释
# 单行注释（v3.7.1 新增）
```

暂不支持多行注释。

> **全角支持**：三言同时识别半角注释 `//`、`#` 和全角注释 `／／`，两者作用完全相同。你可以使用中文输入法直接输入全角注释。


### 2.3 算术运算

| 运算符 | 中文运算符 | 说明                     |
| ------ | ---------- | ------------------------ |
| `+`    | 加         | 加法（自动兼容字符串拼接） |
| `-`    | 减         | 减法                     |
| `*`    | 乘         | 乘法                     |
| `/`    | 除         | 除法（自动兼容浮点数）   |
| `%`    | 余         | 取余                     |
| `^`    | 幂         | 乘方                     |

```c
设 a = 10 + 5;
设 f = 2 ^ 10;       // 1024
```

注意：`加` 操作符在遇到字符串时会自动转为字符串拼接，不会报错。

> **除法**：`/` 运算符执行除法。当两个操作数均为整数且结果为整数时返回整数，否则返回浮点数。
> 例如 `7 / 2` 得到 `3.5`，`6 / 2` 得到 `3`。
> v3.7 起支持浮点数，数字包含小数点时自动识别为浮点数（如 `3.14`），算术运算会自动类型提升。

### 2.4 比较运算

| 运算符 | 中文运算符 | 说明         |
| ------ | ---------- | ------------ |
| `>`    | 大于       | 大于         |
| `<`    | 小于       | 小于         |
| `>=`   | 大于等于   | 大于等于     |
| `<=`   | 小于等于   | 小于等于     |
| `==`   | 等于       | 等于         |
| `!=`   | 不等于     | 不等于       |
| `!>`   | 不大于     | 等价于 `<=`  |
| `!<`   | 不小于     | 等价于 `>=`  |

比较结果：**真**（`+`，整数值 1）或 **假**（`-`，整数值 -1）。

> `不大于` 和 `不小于` 是语义化运算符，分别等价于 `小于等于` 和 `大于等于`，用于提高代码可读性。

### 2.5 逻辑运算

| 运算符 | 说明       | 真值表             |
| ------ | ---------- | ------------------ |
| `且`   | 三值逻辑与 | 真`且`可能 = 可能  |
| `或`   | 三值逻辑或 | 假`或`可能 = 可能  |
| `非`   | 三值逻辑非 | `非`可能 = 可能    |

## 3. 控制流

### 3.1 条件（若/再若/否则）

```c
若 (条件) {
    语句;
} 再若 (条件) {
    语句;
} 否则 {
    语句;
}
```

`再若` 等同于 `否则 若`，可以无限链下去。

### 3.2 循环

```c
设 i = 0;
循环 (i < 5) {
    输出(i);
    i = i + 1;
}
```

循环受步数保护（默认最大 500 步），防止死循环。

### 3.3 遍历

```c
遍历 i 从 1 到 10 {
    输出(i * i);
}
```

### 3.4 返回

`返回` 关键字可在函数内提前退出并返回值。

```c
定义 取绝对值 (x) {
    若 (x >= 0) {
        返回(x);
    };
    返回(-x);
}
```

如果 `返回` 不带参数，默认返回 `0`（TritValue(0)）。

### 3.5 跳出（循环中断）

`跳出` 关键字可立即终止当前 `循环` 或 `遍历`。

```c
遍历 i 从 1 到 10 {
    若 (i > 3) { 跳出 }
    输出(i)
}
// 仅输出 1 2 3
```

与 `跳出` 对应，还有 `继续` 关键字，用于跳过当前循环迭代：

```c
遍历 i 从 1 到 5 {
    若 (i == 3) { 继续 }
    输出(i)
}
// 输出 1 2 4 5
```

### 3.6 三态分支（判）

`判` 语句为三态值提供专用的模式匹配：

```c
判 表达式 {
    真 { 语句; }
    可能 { 语句; }
    假 { 语句; }
}
```

示例：

```c
设 信号 = 随机态()
判 信号 {
    真 { 输出("确定") }
    可能 { 输出("持保留") }
    假 { 输出("否定") }
}
```

`真`、`可能`、`假` 为固定标签，不受皮肤切换影响。

### 3.7 遍历的新形式：遍历-在

除了传统的 `遍历 i 从 1 到 n`，三言支持直接遍历容器（列表、数组、字符串）：

```c
遍历 元素 在 容器 {
    输出(元素)
}
```

例如：

```c
设 数据 = 列表(10, 20, 30)
遍历 值 在 数据 {
    输出(值)
}
// 输出 10 20 30
```

这种方式可避免手动索引，代码更简洁。

---

### 3.8 列表字面量与生成式

除了使用 `列表(...)` 创建列表，三言支持方括号字面量和列表生成式：

```c
设 lst = [1, 2, 3]
设 squares = [x * x 遍历 x 在 lst]
设 evens = [x 遍历 x 在 lst 若 x % 2 == 0]
```

### 3.9 模块导入（命名空间隔离）

导入 命令以命名空间隔离方式加载模块，模块内的定义不会污染全局作用域：


```c
设 数学 = 导入("stdlib/math.san")
输出(数学("平方", 5))
```

与 加载 不同，导入 返回一个可调用的命名空间对象，通过字符串键访问模块内的定义。

## 4. 数据类型

### 4.1 三值整数与三态词

| 三态词                      | 三进制值 | 整数值 |
| --------------------------- | -------- | ------ |
| 开 / 真 / 亮 / 有 / 是     | `+`      | 1      |
| 守 / 可能 / 待 / 未知       | `0`      | 0      |
| 关 / 假 / 灭 / 无 / 否     | `-`      | -1     |

三态词列表可通过皮肤文件扩展。

### 4.1.1 三态词的语义区分

`可能`（也称 `守`、`待`、`未知`）在不同上下文中代表不同的含义：

| 上下文 | 语义 | 示例 |
|--------|------|------|
| **IoT 传感器/执行器** | **保持当前状态** | `置 灯 = 守` 表示"不改变灯的状态" |
| **逻辑/算术运算** | **Kleene 强逻辑的中间值** | `真 且 可能 = 可能` |
| **投票/决策** | **弃权/不确定** | `多数投票([真, 可能, 假])` 将 `可能` 视作不偏向任何一方的中性票 |
| **数据清洗/过滤** | **数据缺失/不确定** | `过滤(函数(x) { x != 可能 }, 数据集)` 用于排除不确定数据 |

**重要**：尽管三态词的整数值都是 `0`，但编程时应根据语义选择合适的同义词，以增强可读性。例如 IoT 场景推荐使用 `守`，推理场景推荐使用 `可能`。

### 4.2 字符串

```c
设 s1 = "你好世界";
设 s2 = 原文{无需引号的文字};
```

字符串可以用 `+` 或 `连接` 拼接，用 `取长` 获取长度，用 `字列` 转为字符列表。

#### 4.2.1 字符串插值（模板）

使用 `模板{...}` 可以直接嵌入表达式，自动展开为 `连接` 调用：

```c
设 温度 = 25
输出(模板{当前温度: ${温度}°C})
// 等价于 输出(连接("当前温度: ", 温度, "°C"))
```

插值可以在任何需要字符串的地方使用。

### 4.3 列表

```c
设 lst = 列表(10, 20, 30);
输出(lst(0));          // 10
置元素(lst, 1, 99);    // 修改
输出(表长(lst));       // 3
```

### 4.4 数组

```c
设 arr = 数组(5);       // 长度5，默认值0
输出(arr(0));           // 0
置元素(arr, 0, 100);
输出(组长(arr));        // 5
```

### 4.5 字典

```c
设 学生 = 字典("姓名", "小明", "年龄", 20);
输出(取键(学生, "姓名"));  // "小明"
置键(学生, "年龄", 21);
```

## 5. 函数

### 5.1 自定义命令（定义）

```c
定义 平方 (x) {
    x * x;
}
输出(平方(6));   // 36
```

### 5.2 匿名函数（函数）

```c
设 加倍 = 函数(x) { x * 2; };
输出(加倍(5));   // 10
```

v3.7.1 起可用希腊字母 `λ` 替代 `函数`：

```c
设 加倍 = λ(x) { x * 2; };
输出(加倍(5));   // 10
```

可直接用在调用处：

```c
输出(应用(函数(x) { x + 1; }, 5));   // 6
```

### 5.3 高阶函数

| 函数                   | 说明             | 示例                                        |
| ---------------------- | ---------------- | ------------------------------------------- |
| `映射(函数, 容器)`     | 对每个元素应用函数 | `映射(加倍, 列表(1,2,3))` → [2,4,6]         |
| `过滤(谓词, 容器)`     | 保留谓词为真的元素 | `过滤(函数(x){x>3;}, 列表(1,3,5))` → [5]   |
| `归并(函数, 容器)`     | 累积计算         | `归并(加, 列表(1,2,3))` → 6                 |

## 3. 错误信息说明

所有运行阶段错误均继承自 `SanyanError`，可被 `尝试/捕获` 捕获：

| 错误类型 | 含义 | 常见原因 |
|----------|------|----------|
| `SanyanNameError` | 未定义的符号/操作 | 变量名拼写错误或未引入 |
| `SanyanSyntaxError` | 参数个数/格式错误 | 内置函数参数不匹配 |
| `SanyanTypeError` | 类型错误 | 参数类型不匹配 |
| `SanyanValueError` | 值错误 | 除数零、负开方、无效输入等 |
| `SanyanRuntimeError` | 运行时错误 | 递归超深、执行中断等 |
| `SanyanKeyError` | 键错误 | 字典中访问不存在的键 |
| `SanyanAttributeError` | 属性错误 | 对非容器做点号访问 |
| `SanyanIOError` | 文件/IO 错误 | 文件读取、写入、加载失败 |
| `SanyanIndexError` | 索引越界 | 列表/数组访问越界 |
| `ReturnException` | 函数返回（内部控制流） | 由 `返回` 关键字触发 |
| `BreakException` / `ContinueException` | 循环中断（内部控制流） | 由 `跳出`/`继续` 关键字触发 |
