2. 基础语法
三言支持两种语法风格，可以混用：

风格	示例
糖语法	设 a = 10;
S 表达式	（设 a 10）
本文档以糖语法为主进行说明。

2.1 变量与赋值
text
设 变量名 = 值;
c
设 年龄 = 25;
设 名字 = "小明";
设 状态 = 开;
支持多重赋值：

c
a = 1;
b = 2;
c = 3;

运算符	中文运算符	说明
+	加	加法
-	减	减法
*	乘	乘法
/	除	整数除法
%	余	取余
^	幂	乘方

2.4 比较运算
运算符	中文运算符	说明
>	大于	大于
<	小于	小于
>=	大于等于	大于等于
<=	小于等于	小于等于
==	等于	等于
!=	不等于	不等于
比较结果：真（+，整数值 1）或假（-，整数值 -1）。
注意：比较失败时可能返回 0（不确定），具体取决于求值情况。

2.5 逻辑运算
运算符	说明	真值表
且	三值逻辑与	真且可能=可能
或	三值逻辑或	假或可能=可能
非	三值逻辑非	非可能=可能
c
输出(真 且 可能);   // 0（可能）
输出(假 或 可能);   // 0（可能）
输出(非 可能);      // 0（可能）
3. 控制流
3.1 条件（若/再若/否则）
c
若 (条件) {
    语句;
} 再若 (条件) {
    语句;
} 否则 {
    语句;
}
再若 完全等同于 否则 若，可以无限链下去。

示例：

c
设 分数 = 85;
若 (分数 >= 90) {
    输出("优秀");
} 再若 (分数 >= 60) {
    输出("及格");
} 否则 {
    输出("不及格");
}
3.2 循环
c
设 i = 0;
循环 (i < 5) {
    输出(i);
    i = i + 1;
}
循环会受到步数保护（默认最大 500 步），防止死循环。

3.3 遍历
c
遍历 循环变量 从 起始 到 结束 {
    语句;
}
示例：

c
遍历 i 从 1 到 10 {
    输出(i * i);
}
4. 数据类型
4.1 三值整数与三态词
三言底层的数字是平衡三进制整数。每个值的内部表示由 +、0、- 组成。

三态词	三进制值	整数值
开 / 真 / 亮 / 有 / 是	+	1
守 / 可能 / 待 / 未知	0	0
关 / 假 / 灭 / 无 / 否	-	-1
4.2 字符串
c
设 s1 = "你好世界";
设 s2 = 原文{无需引号的文字};
连接：

c
连接("你好", "世界");   // => 字符串: 你好世界
取长：

c
输出(取长("hello"));    // 5
拆成字符列表：

c
字列("abc");           // ['a', 'b', 'c']
4.3 列表
c
设 lst = 列表(10, 20, 30);
操作	代码	结果
取元素	lst(0)	10
修改	置元素(lst, 1, 99)	列表变为 [10, 99, 30]
长度	表长(lst)	3
合并	列表合(lst, 列表(1,2))	[10, 99, 30, 1, 2]
4.4 数组
数组是固定长度的容器，创建时必须指定长度。

c
设 arr = 数组(5);       // 长度5，默认值0
设 arr2 = 数组(3, 1);   // 长度3，默认值1
操作	代码	结果
取元素	arr(0)	0
修改	置元素(arr, 0, 100)	数组变为 [100, 0, 0, 0, 0]
长度	组长(arr)	5
转列表	数组列(arr)	[100, 0, 0, 0, 0]
4.5 字典
c
设 学生 = 字典("姓名", "小明", "年龄", 20);
操作	代码	结果
取值	取键(学生, "姓名")	"小明"
设置	置键(学生, "年龄", 21)	修改年龄
直接用	学生("姓名")	"小明"
5. 函数
5.1 自定义命令（定义）
c
定义 函数名 (参数1, 参数2) {
    语句;
}
示例：

c
定义 平方 (x) {
    x * x;
}
输出(平方(6));   // 36
注意：函数的返回值是最后一个表达式的值。

5.2 匿名函数（函数）
c
设 加倍 = 函数(x) {
    x * 2;
};
输出(加倍(5));   // 10
可以直接在调用处定义：

c
输出(应用(函数(x) { x + 1; }, 5));   // 6
5.3 高阶函数
函数	说明	示例
映射(函数, 容器)	对每个元素应用函数	映射(加倍, 列表(1,2,3)) → [2,4,6]
过滤(谓词, 容器)	保留谓词为真的元素	过滤(函数(x){x>3;}, 列表(1,3,5)) → [5]
归并(函数, 容器)	累积计算	归并(加, 列表(1,2,3)) → 6
谓词：返回真（+）或假（-）的函数。

6. IoT 控制
三言内置了传感器和执行器的模拟环境，用于 IoT 编程教学和原型开发。

命令	说明	示例
置 设备 = 状态	设置执行器	置 灯 = 亮;
查 设备	查看设备状态	查 灯;
读 传感器	读取传感器值	设 val = 读 人体;
对 设备 { ... }	在上下文中操作设备	对 灯 { 输出(状态); }
内置设备：

传感器：人体、光线、温度

执行器：灯、风扇、加热

7. 模块与文件
加载模块
c
加载("模块文件.san");
模块文件中的定义（定义 命令）会被导入，文件内的顶层语句也会执行。

创建模块：

c
// utils.san
定义 打招呼 (名字) {
    连接("你好，", 名字);
}
输出("模块加载成功");
使用模块：

c
加载("utils.san");
打招呼("小明");   // 输出 "你好，小明"
