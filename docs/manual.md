## 第一个程序

创建 `hello.san`：

```c
// 智能温室示例
定义 温室控制 () {
    设 温度 = 随机数(10, 35)
    输出(连接("当前温度：", 温度))

    若 (温度 > 30) {
        置 风扇 = 开
        输出("风扇启动")
    } 再若 (温度 < 15) {
        置 加热 = 开
        输出("加热启动")
    } 否则 {
        置 风扇 = 守；// 保持当前状态
        输出("温度适宜")
    }
    返回(0)
}

温室控制()
```

运行：
```bash
python main.py hello.san
```

## 核心概念

### 三值逻辑

三言内置三种状态：

| 值 | 中文 | 含义 |
|---|------|------|
| 1 | 真/开/亮/有 | 确定的肯定 |
| 0 | 可能/守/待/中 | 不确定 |
| -1 | 假/关/灭/无 | 确定的否定 |

```c
// 不确定时保持原状——不需要额外状态变量
若 (读(传感器) == 可能) {
    置 设备 = 守；
}
```

### 两种语法

三言支持两种等价语法：

**糖语法**（类 C，日常使用）：
```c
设 x = 10
若 (x > 5) { 输出("大") }
```

**S 表达式**（Lisp 风格，适合元编程）：
```
(设 x 10)
(若 (大于 x 5) (输出 "大"))
```

### 核心关键字

| 关键字 | 作用 |
|--------|------|
| `设` | 定义变量 |
| `若` / `再若` / `否则` | 条件判断 |
| `循环` | 循环 |
| `遍历` | for 循环 |
| `定义` | 定义函数 |
| `返回` | 函数返回 |
| `尝试` / `捕获` | 异常处理 |
| `输出` | 打印 |
| `导入` | 导入模块 |
| `判` | 三态分支 |

## 2. 基础语法

三言支持两种语法风格，可以混用：

| 风格       | 示例            |
| ---------- | --------------- |
| 糖语法     | `设 a = 10;`    |
| S 表达式   | `（设 a 10）`   |

本文档以糖语法为主进行说明。分号在糖语法中可选（语句结束时可写可不写）。

### 2.1 变量与赋值

```
设 变量名 = 值;
```

```c
设 年龄 = 25;
设 名字 = "小明";
设 状态 = 开;
```

支持多重赋值（省略 `设`）：

```c
a = 1;
b = 2;
c = 3;
```

### 2.2 注释

```c
// 单行注释
# 单行注释（v3.7.1 新增）
```

暂不支持多行注释。

> **全角支持**：三言同时识别半角注释 `//`、`#` 和全角注释 `／／`，两者作用完全相同。你可以使用中文输入法直接输入全角注释。


### 2.3 算术运算

| 运算符 | 中文运算符 | 说明                     |
| ------ | ---------- | ------------------------ |
| `+`    | 加         | 加法（自动兼容字符串拼接） |
| `-`    | 减         | 减法                     |
| `*`    | 乘         | 乘法                     |
| `/`    | 除         | 除法（自动兼容浮点数）   |
| `%`    | 余         | 取余                     |
| `^`    | 幂         | 乘方                     |

```c
设 a = 10 + 5;
设 f = 2 ^ 10;       // 1024
```

注意：`加` 操作符在遇到字符串时会自动转为字符串拼接，不会报错。

> **除法**：`/` 运算符执行除法。当两个操作数均为整数且结果为整数时返回整数，否则返回浮点数。
> 例如 `7 / 2` 得到 `3.5`，`6 / 2` 得到 `3`。
> v3.7 起支持浮点数，数字包含小数点时自动识别为浮点数（如 `3.14`），算术运算会自动类型提升。

### 2.4 比较运算

| 运算符 | 中文运算符 | 说明         |
| ------ | ---------- | ------------ |
| `>`    | 大于       | 大于         |
| `<`    | 小于       | 小于         |
| `>=`   | 大于等于   | 大于等于     |
| `<=`   | 小于等于   | 小于等于     |
| `==`   | 等于       | 等于         |
| `!=`   | 不等于     | 不等于       |
| `!>`   | 不大于     | 等价于 `<=`  |
| `!<`   | 不小于     | 等价于 `>=`  |

比较结果：**真**（`+`，整数值 1）或 **假**（`-`，整数值 -1）。

> `不大于` 和 `不小于` 是语义化运算符，分别等价于 `小于等于` 和 `大于等于`，用于提高代码可读性。

### 2.5 逻辑运算

| 运算符 | 说明       | 真值表             |
| ------ | ---------- | ------------------ |
| `且`   | 三值逻辑与 | 真`且`可能 = 可能  |
| `或`   | 三值逻辑或 | 假`或`可能 = 可能  |
| `非`   | 三值逻辑非 | `非`可能 = 可能    |

## 3. 控制流

### 3.1 条件（若/再若/否则）

```c
若 (条件) {
    语句;
} 再若 (条件) {
    语句;
} 否则 {
    语句;
}
```

`再若` 等同于 `否则 若`，可以无限链下去。

### 3.2 循环

```c
设 i = 0;
循环 (i < 5) {
    输出(i);
    i = i + 1;
}
```

循环受步数保护（默认最大 500 步），防止死循环。

### 3.3 遍历

```c
遍历 i 从 1 到 10 {
    输出(i * i);
}
```

### 3.4 返回

`返回` 关键字可在函数内提前退出并返回值。

```c
定义 取绝对值 (x) {
    若 (x >= 0) {
        返回(x);
    };
    返回(-x);
}
```

如果 `返回` 不带参数，默认返回 `0`（TritValue(0)）。

### 3.5 跳出（循环中断）

`跳出` 关键字可立即终止当前 `循环` 或 `遍历`。

```c
遍历 i 从 1 到 10 {
    若 (i > 3) { 跳出 }
    输出(i)
}
// 仅输出 1 2 3
```

与 `跳出` 对应，还有 `继续` 关键字，用于跳过当前循环迭代：

```c
遍历 i 从 1 到 5 {
    若 (i == 3) { 继续 }
    输出(i)
}
// 输出 1 2 4 5
```

### 3.6 三态分支（判）

`判` 语句为三态值提供专用的模式匹配：

```c
判 表达式 {
    真 { 语句; }
    可能 { 语句; }
    假 { 语句; }
}
```

示例：

```c
设 信号 = 随机态()
判 信号 {
    真 { 输出("确定") }
    可能 { 输出("持保留") }
    假 { 输出("否定") }
}
```

`真`、`可能`、`假` 为固定标签，不受皮肤切换影响。

### 3.7 遍历的新形式：遍历-在

除了传统的 `遍历 i 从 1 到 n`，三言支持直接遍历容器（列表、数组、字符串）：

```c
遍历 元素 在 容器 {
    输出(元素)
}
```

例如：

```c
设 数据 = 列表(10, 20, 30)
遍历 值 在 数据 {
    输出(值)
}
// 输出 10 20 30
```

这种方式可避免手动索引，代码更简洁。

---

### 3.8 列表字面量与生成式

除了使用 `列表(...)` 创建列表，三言支持方括号字面量和列表生成式：

```c
设 lst = [1, 2, 3]
设 squares = [x * x 遍历 x 在 lst]
设 evens = [x 遍历 x 在 lst 若 x % 2 == 0]
```

### 3.9 模块导入（命名空间隔离）

导入 命令以命名空间隔离方式加载模块，模块内的定义不会污染全局作用域：


```c
设 数学 = 导入("stdlib/math.san")
输出(数学("平方", 5))
```

与 加载 不同，导入 返回一个可调用的命名空间对象，通过字符串键访问模块内的定义。

## 4. 数据类型

### 4.1 三值整数与三态词

| 三态词                      | 三进制值 | 整数值 |
| --------------------------- | -------- | ------ |
| 开 / 真 / 亮 / 有 / 是     | `+`      | 1      |
| 守 / 可能 / 待 / 未知       | `0`      | 0      |
| 关 / 假 / 灭 / 无 / 否     | `-`      | -1     |

三态词列表可通过皮肤文件扩展。

### 4.1.1 三态词的语义区分

`可能`（也称 `守`、`待`、`未知`）在不同上下文中代表不同的含义：

| 上下文 | 语义 | 示例 |
|--------|------|------|
| **IoT 传感器/执行器** | **保持当前状态** | `置 灯 = 守` 表示"不改变灯的状态" |
| **逻辑/算术运算** | **Kleene 强逻辑的中间值** | `真 且 可能 = 可能` |
| **投票/决策** | **弃权/不确定** | `多数投票([真, 可能, 假])` 将 `可能` 视作不偏向任何一方的中性票 |
| **数据清洗/过滤** | **数据缺失/不确定** | `过滤(函数(x) { x != 可能 }, 数据集)` 用于排除不确定数据 |

**重要**：尽管三态词的整数值都是 `0`，但编程时应根据语义选择合适的同义词，以增强可读性。例如 IoT 场景推荐使用 `守`，推理场景推荐使用 `可能`。

### 4.2 字符串

```c
设 s1 = "你好世界";
设 s2 = 原文{无需引号的文字};
```

字符串可以用 `+` 或 `连接` 拼接，用 `取长` 获取长度，用 `字列` 转为字符列表。

#### 4.2.1 字符串插值（模板）

使用 `模板{...}` 可以直接嵌入表达式，自动展开为 `连接` 调用：

```c
设 温度 = 25
输出(模板{当前温度: ${温度}°C})
// 等价于 输出(连接("当前温度: ", 温度, "°C"))
```

插值可以在任何需要字符串的地方使用。

### 4.3 列表

```c
设 lst = 列表(10, 20, 30);
输出(lst(0));          // 10
置元素(lst, 1, 99);    // 修改
输出(表长(lst));       // 3
```

### 4.4 数组

```c
设 arr = 数组(5);       // 长度5，默认值0
输出(arr(0));           // 0
置元素(arr, 0, 100);
输出(组长(arr));        // 5
```

### 4.5 字典

```c
设 学生 = 字典("姓名", "小明", "年龄", 20);
输出(取键(学生, "姓名"));  // "小明"
置键(学生, "年龄", 21);
```

## 5. 函数

### 5.1 自定义命令（定义）

```c
定义 平方 (x) {
    x * x;
}
输出(平方(6));   // 36
```

### 5.2 匿名函数（函数）

```c
设 加倍 = 函数(x) { x * 2; };
输出(加倍(5));   // 10
```

v3.7.1 起可用希腊字母 `λ` 替代 `函数`：

```c
设 加倍 = λ(x) { x * 2; };
输出(加倍(5));   // 10
```

可直接用在调用处：

```c
输出(应用(函数(x) { x + 1; }, 5));   // 6
```

### 5.3 高阶函数

| 函数                   | 说明             | 示例                                        |
| ---------------------- | ---------------- | ------------------------------------------- |
| `映射(函数, 容器)`     | 对每个元素应用函数 | `映射(加倍, 列表(1,2,3))` → [2,4,6]         |
| `过滤(谓词, 容器)`     | 保留谓词为真的元素 | `过滤(函数(x){x>3;}, 列表(1,3,5))` → [5]   |
| `归并(函数, 容器)`     | 累积计算         | `归并(加, 列表(1,2,3))` → 6                 |

## 19.x 网络算子（v3.57.0 收口）

> 客户端 `http读`/`http写`/`http请求` + 服务器 `三态Web服务器`/`三态路由`/`三态监听`。
> **完整使用册子（示例全部实测）：`docs/network.md`**。中文 URL/中文路由自动编解码。

**门控与安全**：

- `SANYAN_NET=0` 全局禁网——旧算子抛可读错误，`http请求` 信封报假。
  （与 `SANYAN_FFI` 默认关不同：http 是先于门控发布的既有能力，默认开、显式关。）
- SSRF 防护默认封锁 localhost/私网/保留地址、仅允许 http/https；
  本机自测成环（如连本地 `三态Web服务器`、本地推理端点）设 `SANYAN_NET_ALLOW_LOCAL=1` 显式豁免。
- 超时：默认 60s；作用域内设变量 `超时秒数` 可覆盖（三个客户端算子一致）。

**三态信封（`http请求`）**：与 FFI 信封同构（§20.1，`信封判` 直接可用），
额外携带 `状态码` 与 `响应头`。判 = 真(2xx/3xx) / 假(4xx/5xx、传输失败、被禁)
/ **可能(超时——超时 ≠ 宕机)**。示例（实测）：

```sanyan
设 信封 = http请求("GET", "https://httpbin.org/get")
设 判 = 信封判(信封)
若 (判 == 真) {
    输出(取键(信封, "值"))
} 再若 (判 == 可能) {
    输出("超时,稍后重试")
} 否则 {
    输出(连接("失败: ", 取键(信封, "错"), " 状态码=", 转字符串(取键(信封, "状态码"))))
}
```

（注：`匹配3` 的糖语法尚未实现——仅 S-表达式 AST 路径可用，见 Roadmap 已知限制。）

**Web 服务器**：`三态路由(服务器, 方法, 路径, 处理器)` 的处理器是普通函数，
以**请求字典**为唯一实参（键：`方法/路径/查询/头/体/参数`，`:名字` 路径参数在
`参数` 键）；返回 字符串→text、字典→JSON。零参函数不传参；
传任意表达式则退回旧行为（每请求求值一次，拿不到请求对象）。

**后端矩阵**：解释器路径全量；`http读`/`http写` 另有 LLVM 原生路径（WinHTTP）；
字节码/种子 VM 无网络运行时——编译期显式报错，repl 自动回退求值器。
stdlib：`stdlib/http.san`（薄封装）、`stdlib/network.san`（健康检查/重试，
基于信封三态；真 TCP/UDP 需走 FFI `py导入("socket")`）。

## 19.y 能力约束（`任务` / `约束`）⚗️ 实验性

> 状态：能力层已落地（v3.58.0），仅**解释器路径**支持。三言的定位特性：**让不可信代码变成可以安全运行的代码**。同一份约束声明驱动运行时能力控制与三态失败语义。**完整使用册子见 `docs/constraint.md`**；设计与推翻条件见知识库 `约束-方向研究`。

**心智模型**：`约束{}` 里默认**拒绝一切效果**——只有纯计算恒通；五能力类（`网`/`盘读`/`盘写`/`进程`/`外链`）不 `许` 即判假。四关键字对能力集做运算：

| 关键词 | 语义 | 对能力集 |
|---|---|---|
| `许 X` | 加法授权 | 开一道门 |
| `只许 X` | 封印域 | 能力宇宙=枚举集，域外不在场 |
| `禁 X` | 绝对拒绝（不可逆，`禁`>`许`） | 挖不可覆盖的洞 |
| `允许 可能` | 容忍轴（正交） | 容忍超时的可能，不作错 |

```
任务 导出数据 {
    约束 { 许 盘读; 许 网; 禁 进程 }     // 默认拒绝地板上：开盘读、开网；进程硬禁
    设 信封 = http请求("GET", "http://api.example.com/数据")
    若 (信封判(信封) == 真) { 取键(信封, "值") } 否则 { "走本地缓存" }
}
```

**违规是值,不是异常**：块内未 `许 网` 时，`http请求`（信封式）返回 **判=假、因=约束**（不抛），程序走 `否则` 分支——安全事件降维成控制流，全程无异常。直取式（`http读`/`读文件`）被禁则抛 `约束禁止: 网(http读)`（可 `尝试` 接）。`因` 封闭枚举 `约束|门控|超时|远端|传输`，程序据此分辨"管理员禁止"与"网络故障"。

**探询**：`能否("网")` → 真/假（恒不返回可能——权限是解释器可判定的事实）。`若 (能否("网") == 真) { … } 否则 { 本地缓存() }`。

**性质**：嵌套**单调收紧**（子块只能是父块的子集）；并发/异步子任务**继承** spawn 时的约束（线程不是逃逸口）；能力栈挂求值器实例（不跨实例污染）。**分层律**：`许/禁` 裸用是值层三值构造子（`许(x)→真`），只有在 `约束{}` 里才是能力声明——共享词汇、不共享运行时状态。

**边界**：块级默认拒绝防的是 L0 事故/L1 越界；对抗级（L2）仍需子进程+OS 隔离（不承诺进程内防对抗）。糖 `任务名{约束{…}}` 仅解释器路径；字节码/种子 VM 编译期显式报错。**可判定性法则**：约束只描述能力边界、不描述业务规则（`周一才能联网` 违宪——业务条件用 `若` 包 `任务`）。

## 20. 外语互操作（FFI）⚗️ 实验性

> 状态：Python 桥（层 A）已落地，仅**解释器路径**支持；C 声明导入（层 B）规划中。
> 设计全文见 `docs/ffi_plan.md`。默认**关闭**：设环境变量 `SANYAN_FFI=1` 显式开启。

### 20.1 三态信封

一切外调返回**信封**（含 `判` 键的字典）——判定通道与载荷通道分离：

| 键 | 含义 |
| --- | --- |
| `判` | 三态判定：真=调用成功 / 假=调用失败 / 可能=超时等不确定 |
| `值` | 判=真时的封送结果（Python `False` 封送为 `值=假` 而 `判=真`）|
| `错` | 判=假时的 `异常类型: 消息` |
| `源` | `python`（排障用）|

`解包(信封)`：判真→返回 `值`；判假→抛错；判可能→返回默认值参数（无则抛）。
`或解(信封, 默认)`、`信封判(信封)`（供 `匹配3` 三态分支）同理。

### 20.2 Python 桥六算子

| 算子 | 签名 | 语义 |
| --- | --- | --- |
| `py导入` | `(模块名) → 信封` | 进程内导入，同名幂等返回同句柄 |
| `py取` | `(句柄, 属性名) → 信封` | `getattr`；复杂对象→新句柄 |
| `py调` | `(可调句柄, 参数…) → 信封` | 调用；入参深转换；三言函数值拒（无回调）|
| `py项` | `(句柄, 键) → 信封` | `obj[key]` 下标语义 |
| `py列` | `() → 列表` | 活跃句柄清单（排障）|
| `py释` | `(句柄) → 真` | 释放句柄（幂等）；上限 4096 防泄漏 |

```
(设 j (解包 (py导入 "json")))
(设 d (解包 (py取 j "dumps")))
(输出 (解包 (py调 d (字典 "a" 1))))    ; ⇒ {"a": 1}
```

未开 `SANYAN_FFI` 时同一程序给出可读安全拒绝：`解包失败: FFI 未启用（安全默认）…`。

### 20.3 库层糖（stdlib/ffi.san）

嫌每个外调都包一层 `解包` 啰嗦，可导入 `stdlib/ffi.san`——它把 `解包(py算子(...))`
收进一批便利函数（**失败即抛**，与 `导入` 的失败语义一致）：

```c
导入 "stdlib/ffi.san" 为 ffi
设 j = ffi.库("json")                       // 解包(py导入("json"))
输出(ffi.方法1(j, "dumps", 字典("a", 1)))    // {"a": 1} —— obj.method(x) 一步
```

| 函数 | 等价 | 说明 |
| --- | --- | --- |
| `库(名)` | `解包(py导入(名))` | 导入模块 |
| `成员(句柄, 名)` | `解包(py取(句柄, 名))` | 取属性 |
| `元素(句柄, 键)` | `解包(py项(句柄, 键))` | 下标取值 |
| `调用0..3(可调, …)` | `解包(py调(可调, …))` | 调用（0-3 参）|
| `方法0..2(对象, 名, …)` | `解包(py调(解包(py取(对象, 名)), …))` | `obj.名(…)` 一步 |

这是**库层**便利，不是新语法：底下走同一批算子与信封。**要按三态优雅处理外部失败
（超时/异常分流），仍用裸算子** `匹配3(信封判(py调(f, x))) { 真 → …, 假 → …, 可能 → … }`
——库糖只覆盖"失败即抛"的直路。参数超过上表个数时也回到裸算子。

### 20.4 值封送

Python→三言（返回方向）：`True/False/None → 真/假/可能`；数/串直通；列表/字典**只转一层**
（深容器给句柄）；其它对象给句柄。三言→Python（入参方向）：数值直通（真→1 假→-1 可能→0，
"真即 1"的语言语义）；串/列表/字典深转换；句柄解回原对象（零拷贝）。

### 20.5 后端矩阵与安全

- **仅解释器路径**（`--eval`）支持；默认 VM 模式遇 FFI 程序会打印
  `[FFI] py导入 仅解释器路径支持…` 并**显式回退**求值器执行（不静默）。
- `SANYAN_FFI=1` 才开启；`沙箱("py导入", …)` 可禁；含 FFI 的程序不进差分一致性口径。
- 开启 FFI 即等于授予该 `.san` 程序任意代码执行能力（可读 `os.environ`）——
  **不给不受信来源的程序开 FFI**。
