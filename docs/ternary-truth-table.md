# 三言 贝叶斯 + Kleene 扩展真值表

> Kleene 三值逻辑决定值（离散 1/0/-1），贝叶斯传播决定信度（连续 0-1）。两层独立。

## 裸三态默认信度

| 裸值 | 等价于 |
|------|--------|
| `真` | `三态(真, 1.0, "硬编码")` |
| `假` | `三态(假, 1.0, "硬编码")` |
| `可能` | `三态(可能, 1.0, "硬编码")` |
| `42` | `三态(42, 1.0)` |

## 算术运算

| 表达式 | 值 (Kleene) | 信度 (Bayesian) |
|--------|-------------|------------------|
| `三态(10,0.9) 加 三态(20,0.8)` | 30 | 0.72 (0.9×0.8) |
| `三态(42,0.5) 乘 三态(2,0.6)` | 84 | 0.30 |
| `三态(1,0.7) 减 三态(0,0.9)` | 1 | 0.63 |

## 比较运算

| 表达式 | 值 | 信度 |
|--------|----|------|
| `三态(5,0.9) 大于 三态(3,0.8)` | 真(1) | 0.72 |
| `三态(3,0.4) 小于 三态(5,0.3)` | 真(1) | 0.12 |

## 逻辑运算（信度守恒定律）

| 表达式 | 值 (Kleene) | 信度 (守则) |
|--------|-------------|--------------|
| `三态(真,0.8) 且 三态(可能,0.6)` | 可能 (min) | 0.6 (min) |
| `三态(假,0.9) 或 三态(真,0.7)` | 真 (max) | 0.9 (max) |
| `非 三态(可能,0.5)` | 可能 | 0.5 (keep) |
| `真 且 三态(真,0.3)` | 真 | 0.3 (min) |
| `可能 且 三态(真,0.8)` | 可能 | 0.6 (min) |

## 传播与判定

| 表达式 | 结果 |
|--------|------|
| `传递(三态(真,0.9), 三态(真,0.8))` | 三态(真, 0.72) |
| `判定(三态(真,0.3), 0.5)` | 三态(可能, 0.3) ← 不足门限 |
| `判定(三态(真,0.95), 0.9)` | 三态(真, 0.95) ← 通过 |

## 时间衰减

| 表达式 | 结果 |
|--------|------|
| `三态(真,0.9)` + 1天后 `衰减(v, 0.5)` | C=0.45 |
| `三态(真,0.9)` + 2小时后 `指数衰减(v, 3600, 7200)` | C=0.225 |

## 冲突模型

| 场景 | 结果 |
|------|------|
| `检测冲突(三态(真,0.9), 三态(假,0.85))` | 冲突=1, 差异度=0.85 |
| `冲突合并(a, b, "投票")` | 信度高者胜, C×0.7 |
| `冲突合并(a, b, "保守")` | 三态(可能, 0.5) |

## 信念结构（Agent 记忆单元）

```
信念("老王是好人", 0.72, "老王+小贩", 第12天)
→ {
    命题: "老王是好人",
    值: 三态(真, 0.72),
    信度: 0.72,
    来源: "老王+小贩",
    时间: 第12天
  }

信念集([b1, b2, b3])  ← Agent 记忆容器
```
