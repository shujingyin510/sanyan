# 三言 迁移指南

## v3.22 重大变更

### 三态值系统重构

**新增统一三态类型**
- `TritValue` 现在支持 `_val_type`（数值/字符串/列表/字典）
- 所有值可以携带 `confidence`（信度 0-1）和 `_source`（来源链）

**新增 API**

| 旧方式 | 新方式 |
|--------|--------|
| `真` `假` `可能` | 不变，裸三态默认信度 1.0 |
| `连接(s1, s2)` | 不变，自动解包三态输入 |
| — | `三态值(真, 0.8, "红外")` 带信度+来源 |
| — | `传递(a, b)` 贝叶斯传播 |
| — | `检测冲突(a, b)` 冲突模型 |
| — | `判定(v, 阈值)` 硬判定 |
| — | `衰减(v, 0.5)` 时间衰减 |

**向后兼容**
- 所有现有代码无需修改
- `真`/`假`/`可能` 等价于 `三态(真, 1.0)`/`三态(假, 1.0)`/`三态(可能, 1.0)`
- 算数/比较/逻辑 ops 新接受三态输入，也接受裸值

### 解析器重构

- `parser.py` 重写支持行号/列号追踪
- `sugar/parser.py` `parse_statement` 从 if-elif 链改为字典调度
- 错误信息现在带精确位置

### Agent 变更

- 新增 `信念(命题, 信度, 来源)` 记忆单元
- 启动器 `register_alias` 移到 `init_evaluator` 内
- 好感度规则强制执行
- 元认知反思间隔可配置
