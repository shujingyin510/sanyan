# ADR-010 三态互操作边界（3.59 规格化默认）

- 状态：accepted
- 日期：2026-09-10
- 决策者：项目负责人

## 背景

三态（真/可能/假）与布尔、NULL、异常、状态机的边界主要靠实现与零散文档。  
3.59 批次 3 要把互操作写成规范，必须先定默认，避免规格反复。

## 决策（默认，批次 3 只规格化不扩语义）

| 面 | 默认 |
|----|------|
| 条件 `若` | 真→真分支；假→假/否则；**可能→假 fall-through**，D8 收集诊断（可 `允许` 豁免） |
| 循环条件 | 与 `若` 同：可能按假退出，不无限等 |
| 函数返回 | 可返回可能；调用方自行 `若`/匹配，语言不自动升格为异常 |
| 异常 | 与三态**正交**：异常是控制流跳转，可能是值。约束违规可走「假·因=…」或抛 `SanyanConstraintDenied`（直取式） |
| 布尔/0-1 | `int>0` 为真；`可能` 不是 int 0 的别名（`is_maybe` 仅数值非浮点 trit 0） |
| NULL/缺省 | 无 NULL 一等公民；空/缺省用假、空列表或显式类型 |
| 状态机 | 用三态值作状态合法；不强制把「未知状态」编码为第四态 |
| 约束 | 约束管资格，不管事实；可能只来自世界，不来自权限（分层律） |

## 后果

- 正：批次 3 有稳定默认可写
- 正：与已有测试（D8、约束、S2）一致
- 负：可能在条件中「静默当假」——已有诊断与 `允许` 通道

## 明确不在 3.59

- 改变 `可能` 在条件中的运行时行为
- 引入第四逻辑值
- 把约束违规改成默认抛异常
