# ADR-009 三言 3.59 内部冻结范围（唯一主线）

- 状态：accepted
- 日期：2026-09-10
- 决策者：项目负责人

## 背景

项目目的为**纯兴趣**、时间无限期、主推**本体**。  
Unreleased 已堆积：拆仓扫尾、允许抑制、糖 AST/词法、Windows 种子等。  
需要一条「可规格化、可测试、可审计、可冻结」的完成线，避免无限并行。

## 决策

**3.59 = 内部技术资产冻结，不是对外产品发布。**

成功标准（全部满足才铸版本号）：

1. 约束语义有规格（`docs/constraint.md` 形式语义 + 正反边界测试）
2. 三态互操作有规范（`docs/ternary-logic.md` 新增互操作章节）
3. 差分电池覆盖关键判定（stdout + 约束判定/错误类别/三态值/因）
4. 文档与版本冻结（release notes + 版本号一致，Unreleased 清空）

**批次推进（按可验收产物，不按周）：**

| 批次 | 产出 |
|------|------|
| 1 | 本文件 + 冻结清单 + ADR-008/009/010 |
| 2 | 约束规格化 + 边界测试 |
| 3 | 三态互操作规范 + 矩阵测试 |
| 4 | 差分扩展 + CI + 铸 3.59 |

## 暂停清单（3.59 内不做）

- UR / 论文
- Agent 解冻
- NASM L4 差分闭环
- 类型编译期检查
- 增量 LSP
- 对外发布 / 用户指标 / 商业化
- 自举链升生产（见 ADR-008）

## 后果

- 正：单一主线，AI 可按批次落地；无周计划假 deadline
- 正：Unreleased 漂移被终止
- 负：兴趣驱动下可能想旁路开新刀——用暂停清单挡
