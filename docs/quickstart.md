# 三言快速入门

## 安装

```bash
git clone https://github.com/shujingyin510/sanyan.git
cd sanyan
pip install -e .
```

## 第一个程序

创建文件 `hello.san`：

```san
输出("你好，世界！")
```

运行：

```bash
python main.py hello.san
```

## 基本语法

### 变量

```san
设 x = 10
设 名字 = "三言"
输出(x)
输出(名字)
```

### 条件分支

```san
设 温度 = 25
若 (温度 > 30) {
    输出("热")
} 再若 (温度 > 20) {
    输出("舒适")
} 否则 {
    输出("冷")
}
```

### 循环

```san
设 i = 0
循环 (i < 5) {
    输出(i)
    设 i = 加(i, 1)
}
```

### 函数

```san
定义 加法(a, b) {
    返回(加(a, b))
}
输出(加法(3, 4))  // => 7
```

### 列表

```san
设 列表 = [1, 2, 3, 4, 5]
输出(取(列表, 0))  // => 1
输出(取长(列表))   // => 5
```

### 字典

```san
设 对象 = 字典("名字", "张三", "年龄", 25)
输出(取键(对象, "名字"))  // => 张三
```

## 三态逻辑

三言的核心特性是三态逻辑：真、假、可能。

```san
设 状态 = 可能
若 (状态 == 真) {
    输出("确定")
} 再若 (状态 == 假) {
    输出("否定")
} 否则 {
    输出("不确定")  // => 不确定
}
```

## REPL 交互模式

```bash
python main.py
```

进入 REPL 后可以输入代码即时执行：

```
三言> 设 x = 10
三言> 输出(加 x 5)
=> 15
三言> :help
```

## Web IDE

```bash
python web_ide.py --open
```

在浏览器中打开 http://localhost:8080，可以：
- 编写代码
- 即时运行
- 查看输出
- 加载示例
