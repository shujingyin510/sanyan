# 三言糖语法规范（Sugar Grammar Specification）

本文档定义三言糖语法（Sugar Syntax）的正式语法规则。
糖语法是 S 表达式的语法糖，内部 AST 统一为嵌套列表。

## 1. 词法（Lexer）

### 1.1 字符映射

全角字符自动映射为半角：

| 全角 | 半角 | 全角 | 半角 |
|------|------|------|------|
| `（` | `(` | `）` | `)` |
| `｛` | `{` | `｝` | `}` |
| `［` | `[` | `］` | `]` |
| `＝` | `=` | `＞` | `>` |
| `＜` | `<` | `＋` | `+` |
| `－` | `-` | `＊` | `*` |
| `／` | `/` | `％` | `%` |
| `＾` | `^` | `，` | `,` |
| `；` | `;` | `：` | `:` |
| `！` | `!` | `。` | `.` |
| `　` | ` ` | | |

全角数字 `０-９` 自动映射为 `0-9`。

### 1.2 Token 类型

```
STRING   := '"' ... '"' | "'" ... "'" | '「' ... '」' | '『' ... '』'
           | '"' ... '"' | ''' ... '''
NUMBER   := '-'? DIGIT+ ('.' DIGIT+)?
           | DIGIT+ ('.' DIGIT+)?     （全角数字自动转换）
OP       := '+' | '-' | '*' | '/' | '%' | '^'
           | '=' | '>' | '<' | '>=' | '<=' | '!=' | '!>' | '!<'
IDENT    := 非关键字的标识符（中文/英文/数字/下划线）
COMMENT  := '//' ... '\n' | '／／' ... '\n' | '#' ... '\n'
SYMBOL   := '{' | '}' | '(' | ')' | ';' | ',' | '.' | '[' | ']' | '!' | ':'
```

### 1.3 关键字映射

| 糖语法 | 内部名 | 糖语法 | 内部名 |
|--------|--------|--------|--------|
| `若` | `if` | `否则` | `else` |
| `再若` | `elif` | `遍历` | `for` |
| `循环` | `loop` | `跳出` | `break` |
| `继续` | `continue` | `定义` | `fn` |
| `设` | `set` | `返回` | `return` |
| `输出` | `print` | `做` | `do` |
| `尝试` | `try` | `捕获` | `catch` |
| `导入` | `import` | `导出` | `export` |
| `加载` | `load` | `输入` | `input` |
| `调试` | `debug` | `查` | `query` |
| `对` | `context` | `判` | `judge` |

### 1.4 运算符映射

| 糖语法 | 内部名 | 优先级 |
|--------|--------|--------|
| `+` | `add` | 20 |
| `-` | `sub` | 20 |
| `*` | `mul` | 30 |
| `/` | `div` | 30 |
| `%` | `mod` | 30 |
| `^` | `pow` | 40 |
| `=` | `eq` | 10 |

## 2. 语法（Parser）

### 2.1 程序结构

```
program     := statement*
statement   := set_stmt | fn_stmt | if_stmt | for_stmt | loop_stmt
             | try_stmt | judge_stmt | return_stmt | break_stmt
             | continue_stmt | expr_stmt
```

### 2.2 赋值语句

```
set_stmt    := '设' IDENT '=' expr
```

示例：
```
设 x = 42
设 name = "hello"
设 lst = [1, 2, 3]
```

### 2.3 函数定义

```
fn_stmt     := '定义' IDENT '(' params ')' block
params      := IDENT (',' IDENT)*
block       := '{' statement* '}'
```

示例：
```
定义 add(a, b) {
    返回 a + b
}
```

### 2.4 条件语句

```
if_stmt     := '若' '(' expr ')' block ('再若' '(' expr ')' block)* ('否则' block)?
```

示例：
```
若 (x > 0) {
    输出("正数")
} 再若 (x = 0) {
    输出("零")
} 否则 {
    输出("负数")
}
```

### 2.5 循环语句

```
for_stmt    := '遍历' IDENT '从' expr '到' expr block
             | '遍历' IDENT '在' expr block
loop_stmt   := '循环' '(' expr ')' block
```

示例：
```
遍历 i 从 0 到 10 {
    输出(i)
}

遍历 item 在 lst {
    输出(item)
}

循环 (x < 100) {
    设 x = x + 1
}
```

### 2.6 异常处理

```
try_stmt    := '尝试' block '捕获' ('(' IDENT ')')? block
```

示例：
```
尝试 {
    设 result = 除(1, 0)
} 捕获 (e) {
    输出("错误: " + e)
}
```

### 2.7 三态分支

```
judge_stmt  := '判' expr block block block?
```

示例：
```
判 condition {
    真 { 输出("真") }
    可能 { 输出("可能") }
    假 { 输出("假") }
}
```

### 2.8 表达式

```
expr        := primary (binop expr)?
primary     := NUMBER | STRING | IDENT | '(' expr ')'
             | '[' expr* ']' | '{' (expr ':' expr)* '}'
             | prefix_op expr | fn_expr | call_expr | index_expr

binop       := '+' | '-' | '*' | '/' | '%' | '^'
             | '=' | '!=' | '>' | '<' | '>=' | '<=' | '!>' | '!<'

prefix_op   := '-' | '!'

fn_expr     := '函数' '(' params ')' block
call_expr   := IDENT '(' expr* ')'
index_expr  := primary '[' expr ']'
```

### 2.9 列表和字典

```
list_expr   := '[' (expr (',' expr)*)? ']'
dict_expr   := '{' (expr ':' expr (',' expr ':' expr)*)? '}'
```

示例：
```
设 lst = [1, 2, 3]
设 d = {"name": "小明", "age": 25}
```

## 3. 语义（Semantics）

### 3.1 类型系统

三言是动态类型语言，运行时类型包括：
- **整数**：平衡三进制整数（`TritValue`）
- **浮点数**：定点小数（`TritValue` 带 `precision`）
- **字符串**：UTF-8 字符串
- **列表**：有序元素集合
- **字典**：键值对集合
- **函数**：一等公民，支持闭包
- **模块**：封装的命名空间
- **数组**：固定长度的数值数组（`ArrayValue`）

### 3.2 三值逻辑

比较运算返回三值：
- `1`（真 / T）
- `0`（未知 / U）
- `-1`（假 / F）

逻辑运算遵循 Kleene 三值逻辑：
- `且(T, T) = T`，`且(T, F) = F`，`且(T, U) = U`
- `或(F, F) = F`，`或(T, F) = T`，`或(F, U) = U`
- `非(T) = F`，`非(F) = T`，`非(U) = U`

### 3.3 控制流

- `若`：条件为 `T`（>0）时执行真分支，为 `F`（<0）时执行假分支，为 `U`（=0）时执行假分支
- `循环`：条件为 `T` 时继续循环
- `跳出`：跳出当前循环
- `继续`：跳到下一次循环
- `返回`：从函数返回值

## 4. 示例程序

```
// 完整示例：计算斐波那契数列
定义 fib(n) {
    若 (n <= 1) {
        返回 n
    } 否则 {
        返回 fib(n - 1) + fib(n - 2)
    }
}

设 result = fib(10)
输出(result)  // 55
```

```
// 完整示例：IoT 设备控制
设 温度 = 读传感器("温度")

若 (温度 > 30) {
    置风扇 = 亮
    输出("温度过高，风扇已开启")
} 再若 (温度 < 10) {
    置加热 = 亮
    输出("温度过低，加热已开启")
} 否则 {
    输出("温度正常")
}
```

## 5. 与 S 表达式的对应关系

糖语法在解析后转换为 S 表达式 AST：

| 糖语法 | S 表达式 |
|--------|----------|
| `设 x = 1` | `(set x 1)` |
| `x + y` | `(add x y)` |
| `若 (x > 0) { ... }` | `(if (gt x 0) (do ...))` |
| `定义 f(a) { ... }` | `(fn (f a) (do ...))` |
| `[1, 2, 3]` | `(list 1 2 3)` |
| `f(a, b)` | `(f a b)` |
